About S23 Ultra Debloat Studio

About This Project

This toolkit is an open-source, non-root debloating utility engineered specifically for the Samsung Galaxy S23 Ultra (Snapdragon 8 Gen 2 for Galaxy) running One UI.


Unlike generic debloat scripts that aggressively strip system packages and cause random crashes or break S Pen gestures, this project audits every single package and categorizes them into clear safety tiers.

Key Safety Principles

  • No Root Needed: Runs entirely in user-space using standard Android Debug Bridge commands (pm uninstall -k --user 0).
  • 100% Reversible: System partition APKs are untouched. Any app can be restored instantly via cmd package install-existing.
  • Protected Features: Keeps One-Handed Mode, Adapt Sound EQ, and YouTube untouched unless you deliberately choose to remove them.

How to Use & Fast ADB Setup

1. Enable Developer Options & USB Debugging

  1. On your S23 Ultra, open Settings > About phone > Software information.
  2. Tap Build number 7 times until it says "You are now a developer!".
  3. Go back to Settings > Developer options and toggle USB debugging ON.
  4. Plug your phone into your laptop via USB cable.

2. Two Ways to Run

Option A: WebUSB Direct (Chrome / Edge / Brave)

Click the Connect Phone (WebUSB) button at the top. Allow your browser to pair with the phone and tap Allow USB Debugging on your phone screen.

Option B: Windows Double-Click Script

Simply double-click debloat.bat in the repository folder. It auto-downloads ADB if needed and guides you through an interactive menu!

3. The 3 Traps to Watch Out For:

  • One-Handed Mode (com.sec.android.easyonehand): Do not remove if you shrink the screen on this big phone!
  • Adapt Sound (com.sec.hearingadjust): Do not remove if you customize audio EQ for Galaxy Buds.
  • YouTube (com.google.android.youtube): Keep unchecked unless using YouTube ReVanced.
